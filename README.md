## Run Locally

No build tools or package installation are required for the static
portfolio.

1.  Clone the repository:

    ``` bash
    git clone https://github.com/ImaranMurshad/Portfolio.git
    cd Portfolio
    ```

2.  Open `index.html` in a web browser.

    Alternatively, use the Live Server extension in Visual Studio Code.

## Deployment

The repository includes a GitHub Actions workflow under
`.github/workflows/` for the site's static deployment. Check the
workflow configuration and the repository's GitHub Pages settings for
the active deployment branch and publishing configuration.
