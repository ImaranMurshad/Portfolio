### 🎢 1. Theme Park Ride Monitoring System

**MSc · Fog & Edge Computing · AWS EC2**

A real-time safety monitoring platform using a **Sensor → Edge → Fog →
Cloud** architecture.

**Highlights:** - Virtual ride sensors stream speed, temperature,
vibration, passenger load and brake status over MQTT - Edge layer
performs rule-based anomaly detection and risk scoring - Fog layer
performs rolling-window aggregation and calculates Ride Health Score -
Django REST API provides the cloud backend - Celery + Redis handle
asynchronous tasks and alerts - PDF/CSV exports and filterable analytics
dashboard - Deployed on AWS EC2 using Gunicorn, Nginx and systemd -
Automated CI/CD with GitHub Actions

**Tech:** `Python` `MQTT` `Django` `Celery` `Redis` `AWS EC2` `Nginx`
`GitHub Actions` `ReportLab`

### 🏦 2. Banking Transaction Analytics Pipeline

**MSc · Scalable Cloud Programming · Lambda Architecture**

A real-time banking analytics pipeline built around **Amazon Kinesis,

**Highlights:** - Kinesis streams synthetic banking transactions -

`Chart.js` `Nginx` `GitHub Actions`
